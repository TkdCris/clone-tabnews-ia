# Contexto do Projeto: clone-tabnews-ia

## 1. Visão Geral
* **Objetivo:** Implementação do clone do [TabNews](https://tabnews.com.br) como parte da formação do **curso.dev** (Filipe Deschamps).
* **Abordagem:** Construção de software robusto e profissional, adotando engenharia de software moderna e suporte de agentes autônomos de IA.
* **Stack Base:** Next.js (App Router), React e npm.

---

## 2. Diretrizes e Convenções de Desenvolvimento

### 2.1. Idioma e Nomenclatura
* **Comunicação e Documentação:** Sempre em Português do Brasil (PT-BR).
* **Código:** Nomes de variáveis, funções, classes, arquivos e propriedades em Inglês.
* **Comentários:** Explicativos e concisos em blocos de lógica complexa.

### 2.2. Versionamento (Git)
* **Permissões no Projeto:** Para este projeto, o agente tem permissão para executar comandos Git de escrita e sincronização (`git add`, `git commit`, `git push`, `git pull`, etc.) de forma direta e autônoma, sobrepondo as restrições globais de versionamento.

### 2.3. Qualidade e Execução
* Sempre validar alterações executando a compilação local (`npm run build`) ou a suíte de testes antes de considerar um passo como finalizado.
